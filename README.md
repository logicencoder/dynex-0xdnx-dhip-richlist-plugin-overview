# 0xDNX DHIP Richlist

![0xDNX DHIP Richlist workspace](assets/live-dashboard.png)

Holder rankings become more useful when they can be read alongside recent activity and summary information. The 0xDNX DHIP Richlist brings those views into a WordPress dashboard, helping visitors explore the supported asset's distribution without piecing together several pages.

## Tech stack

| Layer | Technologies |
|---|---|
| Application | PHP, WordPress |
| Supporting technologies | HTML, CSS, JavaScript; Dynex |

## Understand the distribution

Summary statistics provide a starting point before examining individual holders. The dashboard gives visitors an overview of the tracked balances and activity, helping place a single entry in the wider picture. It is a browsing and investigation tool.

The summary provides scale for the holder table. Start there when the question is about the distribution as a whole, then move to an address when a particular entry deserves attention.

![0xDNX DHIP Richlist — Understand the distribution](assets/summary-stats.png)

## Explore ranked holders

The holder table supports working through the distribution in an ordered view. Address information and available navigation help follow an entry of interest, while live refresh keeps the displayed information useful during a session. Visitors can explore without repeatedly rebuilding the same search.

Rank, balance and share describe different aspects of a holding. Reading them together makes the table useful for comparing participants as well as finding a known address.

![0xDNX DHIP Richlist — Explore ranked holders](assets/holder-rankings.png)

## Connect holders with activity

Recent transactions add movement to the static ranking. Reviewing activity beside holder information helps the visitor decide where to investigate further. The dashboard keeps the relevant reference information available for that next step.

A holder's current position and recent activity answer different questions. Keeping both accessible helps visitors examine a movement without losing its place in the wider distribution.

![0xDNX DHIP Richlist — Connect holders with activity](assets/recent-transactions.png)

## Publish the dashboard on WordPress

Embedding support gives the site owner a way to place the richlist within the site's presentation. Search-oriented page support helps the published information fit the wider site. The visitor-facing product remains a coherent dashboard.

The site owner can give the dashboard an appropriate home within an existing page. Visitors then reach the holder information as part of a familiar website experience.

## Operate and maintain the view

Administrator panels cover status, settings, transaction inspection and maintenance tools. These support checking whether the published view is healthy and investigating a data question.

Operational views support the publishing routine behind the public page. Check current status first, then use the transaction and maintenance areas when a specific data question needs more detail.

![0xDNX DHIP Richlist — Operate and maintain the view](assets/admin-dashboard.png)

Database tools give the operator a focused place to inspect the information behind the public richlist. Use them when a question requires more detail than the visitor-facing table provides.

![0xDNX DHIP Richlist — Operate and maintain the view](assets/database-tools.png)

Maintenance controls support keeping the retained information useful over time. They belong to the administrator's publishing routine, alongside status checks and transaction inspection.

![0xDNX DHIP Richlist — Operate and maintain the view](assets/database-maintenance.png)

The transaction browser supports following a particular observation through the retained activity. It provides a more detailed route into a question raised by the summary or holder view.

![0xDNX DHIP Richlist — Operate and maintain the view](assets/transaction-browser.png)
